## gcc
```C
//产生调试文件
gcc -g -o xxxx xxxx.c
//进入gdb环境
gdb
file xxxx
//设置断点
b xxx.c : 15
//运行
run 
//查看变量名
print xxx(变量名)
p xxx(变量名)
//查看变量类型
ptype xxx
//查看端点信息
info b
//删除断点
delete 断点编号
//更改参数值
print xxx(变量名) = xxx
//函数调用堆栈
bt
//单步执行
next  &n
step   &s
//继续执行到下一个断电
continue &c 
//查看文件代码
list &l
//退出gdb
quit &q
```
