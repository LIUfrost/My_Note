# BFS和DFS详细流程解析

我来用详细的步骤和图解来解释BFS（广度优先搜索）和DFS（深度优先搜索）的具体流程。

## 一、BFS（广度优先搜索）

### 1. 核心思想

**一层一层地搜索**，像水面涟漪一样向外扩散。先访问离起点最近的节点，再访问次近的节点。

### 2. 数据结构

- **队列（Queue）**：先进先出（FIFO）
    
- **visited数组**：记录节点是否被访问过
    

### 3. 算法流程

以马走日问题为例，在5×5棋盘上，从(3,3)出发，k=2步：

text

棋盘坐标（1-5）：
   1 2 3 4 5
1  . . . . .
2  . . . . .
3  . . S . .    S = 起点(3,3)
4  . . . . .
5  . . . . .

#### **步骤1：初始化**

text

visited数组：全部为0
队列：空
ans = 0（已访问节点数）
操作：将起点(3,3)加入队列，标记visited[3][3]=1
队列：[ (3,3,step=0) ]
ans = 1

#### **步骤2：处理第0层（步数=0）**

text

出队：取出(3,3,step=0)
检查step=0 < k=2，继续扩展
尝试8个方向：
马走日： (±2,±1) 和 (±1,±2)
方向1: (3-2,3-1) = (1,2) ✓ 在边界内，未访问
    → 加入队列，标记visited[1][2]=1，step=1
方向2: (3-2,3+1) = (1,4) ✓ 加入队列，visited[1][4]=1
方向3: (3+2,3-1) = (5,2) ✓ 加入队列，visited[5][2]=1
方向4: (3+2,3+1) = (5,4) ✓ 加入队列，visited[5][4]=1
方向5: (3-1,3-2) = (2,1) ✓ 加入队列，visited[2][1]=1
方向6: (3-1,3+2) = (2,5) ✓ 加入队列，visited[2][5]=1
方向7: (3+1,3-2) = (4,1) ✓ 加入队列，visited[4][1]=1
方向8: (3+1,3+2) = (4,5) ✓ 加入队列，visited[4][5]=1
此时队列：[ (1,2,1), (1,4,1), (5,2,1), (5,4,1), (2,1,1), (2,5,1), (4,1,1), (4,5,1) ]
ans = 1 + 8 = 9

#### **步骤3：处理第1层（步数=1）**

text

出队：取出(1,2,step=1)
step=1 < k=2，继续扩展
从(1,2)出发的8个方向：
(1-2,2-1)=(-1,1) ✗ 超出边界
(1-2,2+1)=(-1,3) ✗
(1+2,2-1)=(3,1) ✓ 未访问 → 加入队列，visited[3][1]=1，step=2
(1+2,2+1)=(3,3) ✓ 但visited[3][3]=1已访问 → 跳过
(1-1,2-2)=(0,0) ✗
(1-1,2+2)=(0,4) ✗
(1+1,2-2)=(2,0) ✗
(1+1,2+2)=(2,4) ✓ 未访问 → 加入队列，visited[2][4]=1，step=2
继续处理队列中其他step=1的点，每个点都可能产生新的step=2的点

#### **步骤4：处理第2层（步数=2）**

text

出队step=2的点时，因为step >= k，不再扩展，只计数

### 4. BFS流程图解

text

第0层:        (3,3)
             ↓
第1层:  (1,2) (1,4) (5,2) (5,4) (2,1) (2,5) (4,1) (4,5)
         ↓     ↓     ↓     ↓     ↓     ↓     ↓     ↓
第2层:  新点  新点  新点  新点  新点  新点  新点  新点
访问顺序：按层数递增

### 5. BFS代码框架

c

```c
void BFS(int startX, int startY) {
    // 1. 初始化队列
    queue[rear++] = (point){startX, startY, 0};
    visited[startX][startY] = 1;
    ans = 1;
    
    // 2. 循环处理队列
    while (front < rear) {
        // 3. 取出队首元素
        point current = queue[front++];
        
        // 4. 检查是否达到最大深度
        if (current.steps >= k) continue;
        
        // 5. 扩展所有邻居
        for (int i = 0; i < 8; i++) {
            int newX = current.x + dx[i];
            int newY = current.y + dy[i];
            
            // 6. 检查边界和是否访问过
            if (合法 && !visited[newX][newY]) {
                // 7. 标记并加入队列
                visited[newX][newY] = 1;
                queue[rear++] = (point){newX, newY, current.steps + 1};
                ans++;
            }
        }
    }
}

```

## 二、DFS（深度优先搜索）

### 1. 核心思想

**一条路走到黑**，不撞南墙不回头。沿着一条路径尽可能深地搜索，直到无法继续，再回溯尝试其他路径。

### 2. 数据结构

- **栈（Stack）**：后进先出（LIFO），通常用递归实现（系统栈）
    
- **visited数组**：记录节点是否被访问过
    

### 3. 算法流程

同样以马走日问题为例，5×5棋盘，从(3,3)出发，k=2步：

#### **步骤1：初始化**

text

visited数组：全部为0
ans = 0
调用DFS(3,3,0)

#### **步骤2：DFS(3,3,step=0)**

text

访问(3,3)，标记visited[3][3]=1，ans=1
step=0 < k=2，继续
尝试8个方向（按顺序）：
第1个方向：(3-2,3-1)=(1,2)
    ↓ 递归调用DFS(1,2,1)

#### **步骤3：DFS(1,2,step=1)**

text

访问(1,2)，标记visited[1][2]=1，ans=2
step=1 < k=2，继续
尝试8个方向：
第1个方向：(1-2,2-1)=(-1,1) ✗ 边界外
第2个方向：(1-2,2+1)=(-1,3) ✗
第3个方向：(1+2,2-1)=(3,1) ✓ 未访问
    ↓ 递归调用DFS(3,1,2)

#### **步骤4：DFS(3,1,step=2)**

text

访问(3,1)，标记visited[3][1]=1，ans=3
step=2 >= k，达到最大深度，返回（不再扩展）

#### **步骤5：回溯到DFS(1,2,step=1)**

text

继续尝试第4个方向：(1+2,2+1)=(3,3) ✓ 但visited[3][3]=1已访问
第5个方向：(1-1,2-2)=(0,0) ✗
第6个方向：(1-1,2+2)=(0,4) ✗
第7个方向：(1+1,2-2)=(2,0) ✗
第8个方向：(1+1,2+2)=(2,4) ✓ 未访问
    ↓ 递归调用DFS(2,4,2)

#### **步骤6：DFS(2,4,step=2)**

text

访问(2,4)，标记visited[2][4]=1，ans=4
step=2 >= k，返回

#### **步骤7：回溯到DFS(1,2,step=1)**

text

所有8个方向尝试完毕，返回DFS(3,3,step=0)

#### **步骤8：继续DFS(3,3,step=0)的下一个方向**

text

第2个方向：(3-2,3+1)=(1,4)
    ↓ 递归调用DFS(1,4,1)
... 继续这个过程

### 4. DFS递归调用树

text

DFS(3,3,0)
├── DFS(1,2,1)
│   ├── DFS(3,1,2)    [step=2, 到达深度]
│   └── DFS(2,4,2)    [step=2, 到达深度]
├── DFS(1,4,1)
│   ├── DFS(3,3,2)    [已访问，跳过]
│   └── DFS(2,2,2)    [新点]
├── DFS(5,2,1)
│   ├── DFS(3,1,2)    [已访问]
│   ├── DFS(3,3,2)    [已访问]
│   ├── DFS(4,4,2)    [新点]
│   └── DFS(6,4,2)    [越界]
├── DFS(5,4,1)
│   └── ...
└── ... 其他方向

### 5. DFS代码框架

c

```c
void DFS(int x, int y, int steps) {
    // 1. 访问当前节点
    if (!visited[x][y]) {
        visited[x][y] = 1;
        ans++;
    }
    
    // 2. 递归终止条件
    if (steps >= k) {
        return;
    }
    
    // 3. 尝试所有可能的方向
    for (int i = 0; i < 8; i++) {
        int newX = x + dx[i];
        int newY = y + dy[i];
        
        // 4. 检查边界
        if (newX >= 1 && newX <= n && newY >= 1 && newY <= n) {
            // 5. 递归深入
            DFS(newX, newY, steps + 1);
        }
    }
    
    // 6. 注意：这里不需要回溯visited
    // 因为我们需要的是所有可达点，而不是路径
}

```

## 三、BFS vs DFS 对比

### 1. 遍历顺序对比

假设有如下图结构：

text

        A
       / \
      B   C
     / \   \
    D   E   F

**BFS顺序**（队列）：

text

第0层：A
第1层：B, C
第2层：D, E, F
访问顺序：A → B → C → D → E → F

**DFS顺序**（栈/递归）：

text

路径1：A → B → D
路径2：A → B → E
路径3：A → C → F
访问顺序：A → B → D → E → C → F

### 2. 关键区别

|特性|BFS|DFS|
|---|---|---|
|数据结构|队列（Queue）|栈（Stack）/递归|
|遍历方式|按层遍历|深度优先|
|空间复杂度|O(宽度)|O(深度)|
|找最短路径|最优|不一定最优|
|实现难度|较简单|递归简单，迭代较复杂|
