- 多行语句：可以使用反斜杠\来实现多行语句
- 不发生转义：`print(r'hello\n')`
- 同一行现实多条语句：使用;
- 不换行输出：`print(x,end = " ") 或者 print(x,end = "x")以X作为结尾`
- type 和 instance 的差别：
	type()不会认为子类是一种父类类型，而isinstance()会认为子类是一种父类类型
```python
class A:
	pass
class B(A):
	pass
isinstance(B(),A)
True
type(B()) == A
False
```
